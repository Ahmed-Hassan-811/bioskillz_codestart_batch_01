## How to Download a File

1. Open the week's folder and click on the file you need.
2. Click the **download button** (a downward arrow) at the top right of the file.
3. Save it on your computer, then open it in VS Code.

Want everything at once? Click the green **Code** button on the main page of this repository, then **Download ZIP**.

---

## How to Complete and Submit Your Tasks

1. Download the task file, for example `task_01.py`.
2. Rename it with your name: `yourname_task_01.py` (example: `ali_task_01.py`).
3. Solve the **session exercises** (Part A) and the **tasks** (Part B) inside the same file.
4. Run the file in VS Code and make sure it runs without errors.
5. Upload the file to **your own GitHub repository**.

**Deadline:** Every **Friday at 9:00 PM (PKT)** for that week's tasks.

> **Important:** Do not upload your solutions to this repository. Create your own repository (for example, `codestart-tasks`) and upload all your task files there.

### How to upload a file to your own repository

1. Sign in to GitHub and click **New** to create a repository. Make it **Public**.
2. Open your repository and click **Add file**, then **Upload files**.
3. Drag your task file in and click **Commit changes**.

Upload only your task files. There's no need to upload your practice code.
